📷 Motion Detection with Red Movement Highlight
This project is a Python-based motion detection system that uses a webcam or external camera to detect movement in real-time. Whenever motion is detected in the video feed, the affected area is highlighted in red, providing a clear and visual representation of movement.

🔧 Features
🎥 Real-time video streaming from webcam.

🧠 Motion detection using frame differencing.

🟥 Highlights movement areas in red.
